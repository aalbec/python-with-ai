# python-with-ai

A learning resource to help students learn Python with AI.

## Module 1: Basics of AI Python Coding

This module introduces you to Python programming fundamentals while immediately applying them to AI applications. You'll learn to write and run Python code in Jupyter Notebooks and start creating AI-powered tools from day one.

### Learning Objectives

- Python programming fundamentals
- Working with Jupyter Notebooks
- Basic data types and variables
- Functions and LLM interaction
